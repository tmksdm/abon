# Abon

Мобильная PWA для учёта клиентов, абонементов, оплат и сроков продления в небольшом фитнес-зале.

## Разработка

```bash
npm install
npm run dev
```

Полная локальная проверка:

```bash
npm run check
```

Перед продолжением в новом контексте прочитайте `APP_BRIEF.md`, `AGENTS.md` и `docs/PROJECT_STATE.md`.
