# Состояние проекта

## Текущий результат

Этап 0: создан проверяемый каркас мобильной PWA Abon и долговременный контекст для поэтапной разработки.

## Подтверждённое состояние

- Проект создан на React, TypeScript и Vite; подключена генерация service worker и manifest.
- Стартовый экран адаптивен и автоматически следует светлой/тёмной системной теме.
- Название `Abon`, требования к Material Design Icons и правила защиты данных зафиксированы.
- Из старых проектов извлечены основные сценарии: клиенты, оплаты, тарифы, продление, заморозка, архив, история, статистика, импорт/экспорт.
- GitHub Actions настроен на бесплатную публикацию MVP в GitHub Pages после каждого push в `main`.
- PWA проверяет новую версию и показывает пользователю кнопку «Обновить».
- Для синхронизации MVP выбран Firebase Spark без платёжной карты; интеграция будет добавлена отдельным этапом.
- Публичный репозиторий: `https://github.com/tmksdm/abon`.
- Опубликованный MVP: `https://tmksdm.github.io/abon/`.

## Проверки

- `npm run check` — успешно: Oxlint без ошибок, 1 тест пройден, TypeScript и production PWA-сборка успешны; service worker и manifest созданы.
- GitHub Actions run `33251425096` — build и deploy успешны.
- Опубликованные `/abon/` и `/abon/sw.js` отвечают HTTP 200.

## Ограничения и блокеры

- Встроенные плановые бэкапы Firestore требуют Blaze, поэтому в MVP нужна ручная независимая JSON-копия с напоминанием.
- Настоящая установка PWA и поведение офлайна ещё не проверены на физическом iPhone/Android.
